# Installation

## Prebuilt binaries

Download the artifact for your OS from GitHub Releases.

Targets: Windows 64-bit/32-bit, Linux 64-bit/32-bit, macOS Intel/Apple Silicon.

Extract it and run `javli --help` (`javli.exe --help` on Windows).

## From source

```bash
python -m pip install -e .
javli --help
```
