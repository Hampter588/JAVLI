mcli
Minecraft from your terminal

The Minecraft launcher for people who like commands.

Modern Minecraft, preserved historical builds, Microsoft accounts, Java runtimes, instances, modloaders, Modrinth and servers — one CLI.

$ mcli login
✓ Signed in with Microsoft

$ mcli release 1.21.1 --fabric
Launching Minecraft...

$ mcli random --historical
Random pick: b1.7.3 [beta] via omniarchive
MCLI 1.0

One CLI. The Minecraft ecosystem.

Mojang + Omniarchive

Official modern metadata plus direct historical archive discovery.

Microsoft auth

Device-code authentication and multiple Minecraft accounts.

Automatic Java

Managed Java runtimes selected for the Minecraft version.

Modloaders

Fabric, Quilt, Forge and NeoForge launch paths.

Instances

Isolated saves, configs, mods and resource packs.

Modrinth

Search/install mods, dependencies and .mrpack modpacks.

Version discovery

Search and inspect Minecraft across its history.

Servers

Manage isolated vanilla and Paper servers.

Random Minecraft

Pick a random build from the combined catalog and launch it.

Commands

Launch almost anything.

$ mcli release 1.21.1
$ mcli beta b1.7.3
$ mcli classic c0.30
$ mcli release 1.21.1 --fabric
$ mcli instance create survival release 1.21.1
$ mcli mods install sodium --instance survival --loader fabric
$ mcli server create smp 1.21.1
$ mcli random
Install

Get started.

git clone <https://github.com/Hampter588/MCLI>
cd mcli
python -m pip install -e .

$ mcli login
$ mcli release 1.21.1
