JAVLI 1.0

One CLI. Minecraft across generations.

Mojang + Omniarchive

Official modern metadata plus historical Java client discovery.

Microsoft authentication

Device-code sign-in and support for multiple Minecraft accounts.

Automatic Java

Selects the Java runtime required by the Minecraft version.

Fast asset downloads

32 concurrent asset workers with local caching for later launches.

Era-aware memory

Older Minecraft generations get smaller JVM heaps while modern versions receive modern defaults.

Modloaders

Fabric, Quilt, Forge and NeoForge launch paths.

Instances

Isolated saves, configs, mods and resource packs.

Modrinth

Search/install mods, dependencies and .mrpack modpacks.

Servers

Create and manage isolated vanilla and Paper servers.

Commands

Launch almost anything.

$ javli release 26.1.2
$ javli beta b1.7.3
$ javli classic c0.30
$ javli versions --historical
$ javli release 1.21.1 --fabric
$ javli instance create survival release 1.21.1
$ javli mods install sodium --instance survival --loader fabric
$ javli server create smp 1.21.1
$ javli random --historical
